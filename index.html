Ağ Tarama Ayarları

Virgül veya satırla ayrılmış CIDR listesi. Yalnızca yazıcıların bulunduğu ağları yazın — tek taban IP + maske yalnızca bitişik bir blok tarayabildiği için dağınık VLAN'lar kapsanamıyordu. Boş bırakılırsa aşağıdaki taban IP / maske kullanılır.
Bu kadar gündür SNMP/port cevabı vermeyen yazıcı kaydı tarama sonunda listeden düşer. 0 = kapalı (kayıtlar sonsuza kadar birikir).
Toner bu yüzdenin altına düştüğünde yazıcı "Düşük Toner" işaretlenir ve bildirim üretilir. Seviyesi bilinmeyen tonerler hesaba katılmaz.

Active Directory Bağlantısı

⚠️ Uygulama Windows'ta PowerShell RSAT (Active Directory modülü) kullanır ve hesap adını Kerberos/NTLM biçiminde bekler: kullanici@alanadi.local veya ALANADI\kullanici. Linux'ta ise doğrudan LDAP bağlanır ve CN=...,DC=... biçimindeki tam DN kullanılır. Aynı ayar Windows'ta LDAP DN biçiminde girilirse liste boş döner / kimlik doğrulama hatası alınır.
ℹ️ "Bağlantıyı Test Et" her zaman doğrudan LDAP protokolü ile dener. Windows'ta gerçek kullanıcı/grup listesi ise PowerShell RSAT (Active Directory modülü) üzerinden çekilir — bu yüzden test başarılı görünse bile Windows'ta "AD" sekmesi RSAT kurulu değilse veya yukarıdaki hesap Kerberos/NTLM biçiminde girilmemişse boş/hatalı dönebilir.
